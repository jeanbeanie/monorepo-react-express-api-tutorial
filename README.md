# monorepo-react-express-api-tutorial

This repository contains the example code for my tutorial on building a simple monorepo 
with a Vite React frontend and an Express API backend.

If you're following along with the blog post, 
this repo gives you the finished project structure and source code in one place.

## Blog post

Read the full tutorial here: https://jeane.dev/blog/vite-react-spa-node-express-api-monorepo-tutorial/

## What’s included

A simple monorepo setup with:

- a React frontend powered by Vite
- an Express backend API
- shared development in a single repository
- a minimal setup intended for playing/experimenting
